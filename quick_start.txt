MOM — QUICK START (local development on your Mac)
==================================================

All commands run from the project folder, in the VS Code terminal
(menu Terminal → New Terminal, or Ctrl + `):

    cd ~/Developer/myWorkSpace/MOM

Words you will see
------------------
  Terminal   the window where you type commands; press Enter after each one.
  Docker     runs the database and photo storage in "containers", so nothing is
             installed on the Mac itself. Data lives in Docker "volumes":
             mom_pg_data (database) and mom_s3_data (photos).
  .env file  private settings (secrets, keys). Never shared on GitHub.
  Branch/PR  each issue is built on its own branch and merged through a pull request.
  Ctrl + C   stops the program running in that terminal.

What runs where
---------------
  Docker (Docker Desktop must be running):
    PostgreSQL 17 ........ localhost:5432   databases: mom (app), mom_test (tests)
    SeaweedFS (S3) ....... localhost:8333   bucket mom-images (menu & stall photos)
  Node (your terminal):
    API (Fastify) ........ http://localhost:4000      health: /health, API docs: /docs
    Website (Next.js) .... http://localhost:3000      student app; /vendor; /admin


========================================================================
START EVERYTHING (every day)
========================================================================

  1. Open Docker Desktop and wait until it says it's running.

  2. Get the latest merged work (skip if you're in the middle of a branch):

        git switch main
        git pull
        npm install            (only needed when packages changed; safe to run anyway)

  3. Start the databases (Postgres + S3) in the background:

        npm run db:up

  4. Apply any new database changes (safe to run every time; does nothing if up to date):

        npm run db:migrate

  5. Start the API and the website together (leave this terminal open):

        npm run dev

     Wait for "[api] ... Server listening at http://127.0.0.1:4000" and "[web] ✓ Ready",
     then open http://localhost:3000

  Signing in locally: SMS_PROVIDER=console, so no SMS is sent. The 6-digit code is
  PRINTED IN THE TERMINAL running `npm run dev`, in a line starting with
  "📱 SMS (not really sent):".
  Your admin number is the one in SUPER_ADMIN_PHONES in apps/api/.env.


========================================================================
STOP EVERYTHING (end of the day)
========================================================================

  1. In the terminal running `npm run dev`, press  Ctrl + C  (stops API + website).

  2. Stop the databases (YOUR DATA IS KEPT):

        npm run db:down

  3. Optionally quit Docker Desktop.

  If a port is still busy next time ("EADDRINUSE :4000" or ":3000"):

        lsof -nP -iTCP:4000 -sTCP:LISTEN      # shows the process id (PID)
        kill <PID>                             # same for 3000


========================================================================
FIRST-TIME SETUP (new computer, or after deleting the project)
========================================================================

  Needs Node.js 24+ (`node -v`) and Docker Desktop.

        npm install             # installs everything
        npm run setup           # creates apps/api/.env and apps/web/.env.local
        # edit apps/api/.env: SUPER_ADMIN_PHONES (your number) and the Razorpay TEST keys
        npm run db:up
        npm run db:migrate
        npm run db:seed         # default fees, super admin(s), 4 demo stalls
        npm run env:check       # checks the API settings
        npm run dev

  Demo stalls from the seed: Dosa Corner, Chowmein Junction, Odia Thali Ghar, Chai & Rolls.


========================================================================
USEFUL EXTRAS
========================================================================

  Databases
    npm run db:psql        open a SQL prompt on the app database (type \q to leave)
    npm run db:logs        follow Postgres / S3 logs (Ctrl + C to stop following)
    npm run db:seed        add the demo data again (safe to repeat)
    npm run db:reset       ⚠ DELETES ALL LOCAL DATA, then migrates and seeds afresh

  Checks and tests (the same as GitHub CI)
    npm run check          format + lint + typecheck + unit tests
    npm run test:int       API integration tests (needs `npm run db:up`)
    npm run e2e -w @mom/web
                           browser tests: builds the site, starts its own API (:4100) and
                           website (:3100) against mom_test, runs Playwright, stops them.
                           Stop `npm run dev` first if your Mac is slow.

  Payments (Razorpay test mode)
    - Keys live ONLY in apps/api/.env (git-ignored). Never commit them.
    - UPI at checkout appears for a stall only when its settlement account is active:
      admin → Stalls → the stall → UPI payouts → "Mark active (test mode)",
      then the stall turns UPI on in its Settings.
    - Turn on UPI in the Razorpay dashboard (test mode) to see UPI in the payment window.

  Git workflow used so far
    one branch per issue → push → pull request → CI must pass → squash-merge into main


========================================================================
TROUBLESHOOTING
========================================================================

  "Cannot connect to the Docker daemon"   Docker Desktop isn't running: open it, wait, retry.
  API exits with "invalid environment"    run `npm run env:check`; it says which setting is wrong.
  "relation ... does not exist" / column  run `npm run db:migrate`.
  Photos don't upload or show             `npm run db:up` (the S3 container must be running).
  Login code never arrives                look in the `npm run dev` terminal (console SMS mode).
  "Too many codes requested"              wait an hour, or use another number
                                          (limits: 5 codes per number, 30 per network, per hour).
