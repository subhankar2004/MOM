WHERE WE ARE
------------
We are rebuilding MOM from scratch, one GitHub issue at a time.
The old prototype (Supabase + Expo) is saved under the git tag
"prototype-v0". The plan is in spec.md, the to-do list is on GitHub:
    https://github.com/subhankar2004/MOM/issues

Right now (after issue #1) the project is only the empty skeleton:
there is nothing to "run" yet. The local database arrives in issue #2,
the API in #5 and the website in #6 — this guide grows with them.


WORDS YOU WILL SEE
------------------
  Terminal   = the window where you type commands. In VS Code:
               menu  Terminal → New Terminal   (or press  Ctrl + ` )
  Command    = a line you type in the Terminal, then press Enter.
               Only type the part AFTER the "$ " sign.
  Branch     = a separate copy of the code where one issue is worked on.
  PR         = Pull Request: asks GitHub to merge a branch into "main".
  Ctrl + C   = stops a running program in the Terminal.


ONE-TIME SETUP (on a new computer)
----------------------------------
    $ git clone https://github.com/subhankar2004/MOM.git
    $ cd MOM
    $ npm install


CHECK THAT EVERYTHING IS OK
---------------------------
    $ cd /Users/subhankarpatra/Developer/myWorkSpace/MOM
    $ npm run check        (format + lint + typecheck — must say no errors)


GET THE LATEST CODE AFTER A PR IS MERGED
----------------------------------------
    $ git switch main
    $ git pull
    $ npm install          (only needed if package.json changed)

The full branch → PR → merge routine is in CONTRIBUTING.md.
