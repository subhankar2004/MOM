WHAT IS WHAT (read this once)
-----------------------------
Your project folder:  /Users/subhankarpatra/Developer/myWorkSpace/MOM

  supabase/   = the BACKEND (database, login, payment code).
                While developing, it runs on YOUR MAC inside Docker.
                Later, for real students, it moves to supabase.com (Part 6).
  web/        = the WEBSITE (students order here; stall owners and you
                (admin) manage things here).
  mobile/     = the PHONE APP. You open it on your phone with "Expo Go".

The backend's data is kept in its OWN Docker volumes (you can see them
in Docker Desktop → Volumes):

    supabase_db_mom              ← the database (stalls, menus, orders, users)
    supabase_storage_mom         ← uploaded files (images later)
    supabase_edge_runtime_mom    ← payment functions cache

They belong only to MOM — your other projects' volumes are not touched.

Words you will see:
  Terminal   = the window where you type commands. In VS Code:
               menu  Terminal → New Terminal   (or press  Ctrl + ` )
  Command    = a line you type in the Terminal, then press Enter.
               Only type the part AFTER the "$ " sign.
  Server     = a program that keeps running in a Terminal. While it runs,
               that Terminal is "busy" — open a NEW Terminal tab (the "+"
               button in VS Code's Terminal panel) for other commands.
  Ctrl + C   = how you STOP a server (hold Control, press C).
  .env.local = small private settings file with keys/addresses.

PART 2 — EVERY DAY: STARTING THE PROJECT  (2 Terminals)
=====================================================================

STEP 2.0  Open Docker Desktop
-----------------------------
Open the "Docker Desktop" app (Applications folder or Spotlight: Cmd+Space,
type Docker). Wait until the bottom-left shows it's running.
Without Docker running, the backend cannot start.


STEP 2.1  Start the BACKEND  (Terminal 1)
-----------------------------------------
    $ cd /Users/subhankarpatra/Developer/myWorkSpace/MOM
    $ npm run db:start

Takes ~20 seconds. When it finishes it prints a block of text with
addresses — that means it worked. This one does NOT stay busy; the
backend keeps running inside Docker after the command ends.

Useful backend pages (open in your browser):
    http://127.0.0.1:54323   Supabase Studio — SEE AND EDIT YOUR DATABASE
                             (Table Editor → stalls, menu_items, orders…)
    http://127.0.0.1:54324   Mailpit — the LOCAL EMAIL INBOX.
                             Login codes are "sent" here, not to real email.


STEP 2.2  Start the WEBSITE  (same Terminal 1 is fine)
------------------------------------------------------
    $ npm run web

Wait until you see  "Ready". LEAVE THIS TERMINAL RUNNING.
Open your browser:   http://localhost:3000


STEP 2.3  Start the PHONE APP  (Terminal 2 — click "+" for a new tab)
---------------------------------------------------------------------
    $ cd /Users/subhankarpatra/Developer/myWorkSpace/MOM
    $ npm run mobile

A big QR code appears. LEAVE THIS TERMINAL RUNNING.
  • Android: open Expo Go → "Scan QR code" → scan it.
  • iPhone:  open the Camera app → point at the QR → tap the link.

IMPORTANT: phone and Mac must be on the SAME Wi-Fi, and the phone talks to
your Mac using its Wi-Fi address (see Part 8, "phone can't load stalls").

Handy keys in this Terminal:   r = reload app    w = open in browser

PART 4 — CLOSING / STOPPING EVERYTHING
=====================================================================
1. Terminal running the WEBSITE   → click in it → press  Ctrl + C
2. Terminal running the PHONE APP → click in it → press  Ctrl + C
3. Stop the backend (any Terminal):
       $ cd /Users/subhankarpatra/Developer/myWorkSpace/MOM
       $ npm run db:stop
4. Close Expo Go on your phone. You may quit Docker Desktop now.

YOUR DATA IS SAFE: db:stop keeps the "supabase_db_mom" volume, so your
stalls, users and orders are still there next time you run db:start.

⚠  Never press the 🗑 delete button on the "..._mom" volumes in Docker
   Desktop unless you WANT to erase all MOM data.

PART 8 — COMMON PROBLEMS
=====================================================================
"Cannot connect to the Docker daemon" / db:start fails
    → Docker Desktop isn't open/running. Open it, wait, try again.

"port is already allocated" on db:start
    → Another project's Supabase is running. Stop it, or run
      npm run db:stop  then  npm run db:start.

"Port 3000 is already in use"
    → Website already running in another Terminal. Or run:
          $ lsof -ti:3000 | xargs kill

Login code never arrives
    → Locally, emails go to http://127.0.0.1:54324 (Mailpit), NOT to
      your real inbox.

No stalls showing on the website
    → Backend not running (Step 2.1), or run  npm run db:reset.

Phone app: can't load stalls / network error
    → Your Mac's Wi-Fi address changed (it does when you change Wi-Fi).
      Find it:   $ ipconfig getifaddr en0
      Put it in  mobile/.env.local  (both lines that have an IP), then
      stop the phone app (Ctrl + C) and run  npm run mobile  again.
    → College Wi-Fi often blocks phone↔laptop traffic. Use your phone's
      hotspot for the Mac, or test the app in the browser (press  w ).

Changed a .env.local file but nothing changed
    → Stop that server with Ctrl + C and start it again.

Expo Go says the project needs a newer/older SDK
    → Update Expo Go from the Play Store / App Store.

Anything else → copy the red error text and ask Claude. 🙂
